# JGR 2026 Data Visualization
Analysis and visualization of Joe Gibbs Racing drivers during the 2026 NASCAR Cup Series season.

## Drivers
- Denny Hamlin
- Christopher Bell
- Chase Briscoe
- Ty Gibbs

## Visualization
### Points Per Race
Line chart comparing points earned by each JGR driver throughout the 2026 season.
Race number is used to maintain chronological order, with track names displayed on the x-axis.
